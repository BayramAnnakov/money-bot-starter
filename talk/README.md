# The talk

**FirstDollar — what $100 and 28 days of an autonomous agent actually bought.**
5 minutes, main stage, [AI Tinkerers Seattle](https://seattle.aitinkerers.org/), 19 August 2026.

📄 **[firstdollar-ai-tinkerers-2026-08-19.pdf](firstdollar-ai-tinkerers-2026-08-19.pdf)** — the deck as
presented. 13 pages, because each click-to-reveal build step is its own page.

It is the same null result as [LESSONS.md](../LESSONS.md), told in the order it happened:

| pages | what is on them |
|---|---|
| 1–2 | the tweet that started it — an agent earning $98.68 in three days from a two-sentence prompt — and the replication: $100, 28 days, cron |
| 3 | the rig: constitution, `PreToolUse` spend gate, $100 card cap, `Stop` hook, owner-authenticated approvals |
| 4–6 | two receipts side by side: his $98.68, mine $0.00, stamped UNPAID |
| 7 | three verbatim lines from the agent's own journal, including it catching its own flattering self-assessment |
| 8 | why zero: 10 blocking gates — **7 identity**, 3 toolchain, 0 "couldn't do the work" |
| 9–10 | lesson 1 — the completion contract stayed green for three days while the sandbox was down |
| 11 | lesson 2 — the gate is per-action, the agent is per-outcome: 42 runs, 41 "complete", 0 earning attempts |
| 12 | lesson 3 — a second model reviewed this harness before launch and found ten defects the author found none of |
| 13 | what survives: the card cap, the append-only trail, scoped approvals, one door into the sandbox |

The closing line is the one that matters for anyone building on this scaffold: the first hard problem
in autonomous companies is not the model, it is **admission and settlement** — accounts, terms,
identity checks, and the bank account the money finally lands in. All of that still needs a person.
