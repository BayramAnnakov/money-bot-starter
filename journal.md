# Journal — append-only, one bounded entry per run

The narrative layer: what the ledger can't hold — beliefs, surprises, updates. Append only,
newest at the bottom, ≤ 35 lines per entry (this is a journal, not a memoir). Link decision ids
(`decisions.md`) and forecast ids (`forecasts.md`) instead of restating them.

Template:

```
## Day N — YYYY-MM-DD (run <run_id>)
**Going in:** 2-3 bullets — what I believe, what today is for.
**Did:** every externally-visible action, one line each, with URL/id.
**Got:** what came back — numbers, replies, silence. Evidence links.
**Surprised by:** the one thing that didn't match expectations (or "nothing").
**Updated:** belief changes + forecast ids touched (F3 opened at p=0.4, F1 resolved 0).
**For the owner:** asks, if any (also pinged via request-approval).
```
